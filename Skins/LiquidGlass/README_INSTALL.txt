WindowsLiquidGlass LiquidGlass Rainmeter Suite

Includes:
- ControlCenter.ini
- SystemGlass.ini
- ClockGlass.ini

Install:
1. Install Rainmeter from https://www.rainmeter.net/
2. Copy folder "WindowsLiquidGlass_LiquidGlass" to Documents\Rainmeter\Skins\
3. Open Rainmeter and refresh all.
4. Load the skins you want.

These skins are inspired by liquid-glass aesthetics but designed safely for Windows.
